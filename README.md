# Creative Developer Portfolio

A responsive React + Vite portfolio starter with a dark creative design.

## Start

1. Install Node.js 20 or newer.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the localhost URL printed in the terminal.

## Customize

- Edit `src/main.jsx` to change the introduction, project descriptions, and skills.
- Replace `YOUR_EMAIL@example.com` with your actual contact email.
- Edit `src/style.css` to change colors, layout, and effects.
- Replace the abstract project artwork with screenshots or video previews when ready.
- Add links to your actual Roblox experiences, repositories, and project demos.

## Deploy

Run `npm run build` and deploy the `dist` directory to a static hosting provider such as Vercel or Netlify.

Project descriptions are based on initial planning and should be reviewed before publishing.
